# Cloud Security Lab - Power BI Dashboard

## Overview

This directory contains the Power BI dashboard developed for **Cloud Security Lab**.

The dashboard transforms the security events and alerts generated by the platform into interactive visualizations that support security monitoring and incident investigation.

---

# Requirements

Before opening the dashboard, ensure the following components are available:

* Microsoft Power BI Desktop
* PostgreSQL
* Cloud Security Lab database
* Events and Alerts tables populated with data

---

# Database Connection

The dashboard expects a PostgreSQL database containing the following tables:

* `events`
* `alerts`

If the database server or credentials differ from the original development environment:

1. Open the `.pbix` file.
2. Select **Transform Data**.
3. Open **Data Source Settings**.
4. Modify the PostgreSQL connection parameters.
5. Apply the changes.
6. Refresh the dataset.

---

# Dashboard Pages

## Executive Overview

Provides a high-level summary of platform activity.

Main indicators include:

* Total Events
* Total Alerts
* Active Users
* Active IP Addresses
* Event Distribution
* Alert Distribution

---

## IP Analysis

Focuses on network activity.

This page helps identify:

* Most active IP addresses
* IPs generating alerts
* Event distribution by IP
* Alert distribution by IP

---

## User Analysis

Analyzes user behavior.

This page provides information about:

* Users generating the highest activity
* Failed login attempts
* Users associated with alerts

---

## Resource Analysis

Displays information related to accessed resources.

The objective is to identify:

* Most accessed resources
* Resource access distribution
* Potential resource enumeration patterns

---

## Incident Investigation

Provides a detailed view of the generated events and alerts.

This page is intended for incident reconstruction by allowing analysts to:

* Review the event timeline
* Examine generated alerts
* Filter by user
* Filter by IP address
* Investigate attack sequences

---

# Data Refresh

Whenever new simulations are executed:

1. Ensure the new events have been stored in PostgreSQL.
2. Open the Power BI report.
3. Click **Refresh**.

The dashboard will automatically update all visualizations.

---

# Purpose

The Power BI dashboard is intended to complement the Cloud Security Lab backend by providing an interactive environment for exploring security events, understanding detection results and supporting incident analysis.

It is not intended to replace a commercial SIEM dashboard but rather to demonstrate how security telemetry can be transformed into actionable visual information.
